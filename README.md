# MASTERME4A Bot Control

Flutter Android starter for the purple MASTERME4A control-panel prototype.

## Build APK
GitHub Actions runs on pushes to main or manually:
1. Open Actions.
2. Select **Build MASTERME4A Android APK**.
3. Run workflow if needed.
4. Download artifact **MASTERME4A-Bot-Control-Android** from a successful run.

This is currently a UI prototype. Bot networking and Minecraft control are not implemented.
